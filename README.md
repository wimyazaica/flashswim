# FLASH SWIM

Сайт школы плавания FLASH SWIM: занятия и цены, расписание, тренеры, спортивные сборы, отзывы и запись. Статический HTML/CSS/JavaScript, без сборки и сторонних npm-зависимостей. Готовые файлы сайта находятся в `dist/`.

## Локальный запуск

Нужен Node.js 18 или новее. Из корня проекта выполните:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Устанавливать npm-пакеты не требуется.

## Версия для передачи коллеге

```sh
node scripts/prepare-preview.mjs ./preview
```

Откройте `preview/index.html` двойным щелчком после полного извлечения папки из ZIP. Установка программ и запуск сервера для просмотра не нужны. После изменений повторите экспорт. Плейлист первого экрана встраивается в HTML, поэтому работает и при открытии файла без сервера.

Видео, фотографии, шрифты и анимации хранятся локально. Для живой карты, построения маршрутов, отзывов Яндекса, переходов в WhatsApp и Telegram нужен интернет.

## Где менять содержимое

| Файл | Содержимое |
| --- | --- |
| `dist/index.html` | Тексты, цены, структура, фотографии по разделам, галерея сборов, контакты, ссылки на оферту и политику |
| `dist/app.js` | Два бассейна, расписание, тренеры, выбор дня и времени, кнопки записи, живая карта и маршруты |
| `dist/hero-media.json` | Первый экран: видео тренировок, затем одна фотография команды |
| `dist/hero-media.js` | Плавная смена фото и видео, пауза, звук и восстановление при ошибке загрузки |
| `dist/hero-layout.css` | Первый экран: текст слева, видео справа с сохранением пропорций |
| `dist/camp-gallery.js`, `dist/camp-gallery.css` | Галерея пяти фотографий сборов: нажатие на фото, стрелки, миниатюры, клавиатура и свайп |
| `dist/moments.css` | Фотографии рядом с информацией о занятиях, бассейне и тренерах |
| `dist/locations.css` | Живая Яндекс-карта и форма построения маршрута |
| `dist/ocean.css`, `dist/readability.css` | Бирюзовая тема, читаемость и адаптивная верстка |
| `dist/swim-motion.js`, `dist/swim-motion.css` | Натуральные движения пловцов, четыре стиля плавания и дорожки без текстовых подписей |
| `dist/assets/` | Видео, фотографии, шрифты и лицензия шрифта |

Пять снимков сборов размещены в галерее раздела «Сборы». Остальные четыре фотографии распределены по сайту: одна сменяет видео на первом экране, три иллюстрируют цены и форматы, бассейн и команду тренеров. Отдельного раздела «Фото» нет.

Кнопки записи открывают реальные контакты школы в WhatsApp или Telegram с выбранными форматом, бассейном, днём и временем. Запись подтверждает администратор; отдельного сервера приёма заявок нет.

Внизу расположены живая карта Яндекса в iframe и виджет отзывов. Можно выбрать один из двух бассейнов, ввести начальный адрес и построить маршрут на машине, общественном транспорте или пешком. Маршрут показывается на карте; отдельная ссылка открывает его в Яндекс Картах. Адрес отправления не сохраняется сайтом и передаётся Яндексу для построения маршрута.

Бесплатный виджет Яндекс Карт может показывать рекламу. Интерфейс и реклама Яндекса не скрываются. Для гарантированного отключения рекламы нужен соответствующий тариф Яндекса и API-ключ. Время занятий и наличие мест следует подтверждать у администратора.
