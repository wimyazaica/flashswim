# FLASH SWIM

Сайт школы плавания FLASH SWIM: занятия и цены, расписание, тренеры, сборы, галерея фотографий, отзывы и запись. Статический HTML/CSS/JavaScript, без сборки и сторонних npm-зависимостей. Готовые файлы сайта находятся в `dist/`.

## Локальный запуск

Нужен Node.js 18 или новее. Из корня проекта выполните:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Устанавливать npm-пакеты не требуется.

## Автономная версия для просмотра

```sh
node scripts/prepare-preview.mjs ./preview
```

Откройте `preview/index.html` двойным щелчком. Папку `preview` можно целиком передать коллеге или упаковать в ZIP. После изменений повторите экспорт. Видео, фотографии и шрифты хранятся локально; для отзывов Яндекса и переходов к контактам нужен интернет.

## Где менять содержимое

| Файл | Содержимое |
| --- | --- |
| `dist/index.html` | Тексты, цены, структура, галерея `#photos`, контакты, ссылки на оферту и политику |
| `dist/app.js` | Бассейны, расписание, тренеры, выбор дня и времени, кнопки записи |
| `dist/hero-media.json` | Очерёдность медиа: сначала видео 916 × 512, около 21 секунды, затем семь фотографий |
| `dist/hero-media.js` | Плавная смена фото и видео, пауза, звук и восстановление при ошибке загрузки |
| `dist/hero-layout.css` | Первый экран: текст слева, видео справа с сохранением пропорций |
| `dist/ocean.css`, `dist/readability.css` | Бирюзовая тема, читаемость и адаптивная верстка |
| `dist/swim-motion.js`, `dist/swim-motion.css` | Пловцы, четыре стиля плавания и разноцветные дорожки |
| `dist/assets/` | Видео, фотографии, шрифты и лицензия шрифта |

В разделе «Фото» (`#photos`) показаны пять снимков бассейна, занятий в зале и команды. Нажатие на снимок открывает оригинал в новой вкладке.

Кнопки записи открывают реальные контакты школы в WhatsApp или Telegram с выбранными форматом, бассейном, днём и временем. Запись подтверждает администратор; отдельного сервера приёма заявок нет.

Внизу рядом расположены схема бассейна без рекламы и настоящий виджет отзывов Яндекса. Схема не является точной картой: маршрут открывается по ссылке в Яндекс Картах. Время занятий и наличие мест следует подтверждать у администратора.
